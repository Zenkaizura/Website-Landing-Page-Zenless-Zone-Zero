01 BREAK THEIR DEFENSE

Daze & Stun

Setiap serangan meningkatkan indikator Daze musuh. Saat mencapai 100%, musuh memasuki kondisi Stun dan menerima damage lebih besar. Ini waktumu melancarkan serangan terbaik.

DAZE ACCUMULATION100% / STUNNED

PROXY TIP ↗ Gunakan Agent Stun untuk membuka kesempatan bagi penyerang utama.

02 KEEP IT GOING

Chain Attack

Serangan berat pada musuh dalam kondisi Stun dapat memicu Chain Attack. Pilih Agent berikutnya untuk menyambung serangan dan memaksimalkan kesempatan saat musuh tak berdaya.

AGENT 01→AGENT 02→AGENT 03

PROXY TIP ↗ Susun urutan pergantian agar buff tim mendukung penyerang utamamu.

03 TIMING IS EVERYTHING

Dodge & Assist

Lakukan Perfect Dodge sesaat sebelum serangan mengenai Agent untuk membuka Dodge Counter. Kilatan serangan tertentu juga bisa ditanggapi dengan pergantian Agent untuk memicu Assist.

DODGE✳COUNTER

PROXY TIP ↗ Perhatikan isyarat visual musuh. Timing yang tepat lebih berharga daripada menekan tombol terus-menerus.

04 MAKE AN IMPACT

Attribute Anomaly

Serangan atribut mengisi indikator Anomaly. Saat penuh, efek seperti Burn, Freeze, Shock, Corruption, atau Assault dapat terpicu. Kombinasikan atribut untuk membuka strategi tim berbeda.

PhysicalFireIce ElectricEther

PROXY TIP ↗ Memicu Anomaly berbeda sebelum efek sebelumnya habis dapat menghasilkan Disorder.
